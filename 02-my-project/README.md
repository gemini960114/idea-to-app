# 第三堂（下）｜接手自己的專案：把 AI Studio 的作品搬進 Antigravity

第三堂，約 90 分鐘。把你在 **Google AI Studio** 做好的作品搬到這台電腦，請 AI 解說、跑起來，再請它幫你**修改一項功能**。

**重點：從今天起，作品的每個檔案都在你手上。** 你可以看懂它、改它，也要負責檢查它。

> **課前準備**：完成 [安裝環境](../01-install/README.md) 的 Step 1～5（暖身用的 `my-first-project` 資料夾不用保存）。準備好你的 AI Studio 作品：有存到 GitHub 的，記下 repo 網址；沒有的，等一下在 Step 1 下載成 ZIP 檔。
>
> 如果你還沒有 AI Studio 作品，改做文末的 [附錄：從零做一個小遊戲](#附錄從零做一個小遊戲)。

| | 在 AI Studio | 在 Antigravity |
| :--- | :--- | :--- |
| 程式在哪裡 | Google 的雲端 | **這台電腦上** |
| 怎麼改 | 跟 AI 對話 | 跟 AI 對話，也能直接看、改每一個檔案 |
| 版本紀錄 | 有限 | **git**：每一次修改都記得（第四堂會細講） |

## Step 1：把作品搬到電腦上

在「文件」（Documents）裡新建一個空資料夾，取一個好認的英文名字，例如 `my-app`，用 **Open Folder** 打開。

接著照 [登入 GitHub](../01-install/README.md#登入-github每次上課都要做) 的步驟登入 GitHub：下課前要用它保存作品，私人的 repo 也要登入才能下載。

再依你的情況選一種：

**A. 作品已經在 GitHub 上**

**Prompt 3：從 GitHub 下載**

```text
請把 〔你的 GitHub repo 網址〕 用 git clone 下載到這個資料夾裡（直接放在目前資料夾，不要多一層）。
```

**B. 只有 ZIP 檔**

用這台電腦的瀏覽器登入 [Google AI Studio](https://aistudio.google.com)，打開你的作品，把它下載成 ZIP 檔（會存在「下載」資料夾）。在家下載的檔案不會在這台電腦上，要在教室重新下載一次。

把 ZIP 檔解壓縮，把裡面的檔案全部放進 `my-app`（打開 `my-app` 時，要直接看得到 `package.json`、`src` 這些檔案）。

## Step 2：請 AI 解說，再跑起來

**Prompt 4：解說並啟動**

```text
請用高中生聽得懂的方式介紹這個專案：它是什麼 App、有哪些主要檔案、各自負責什麼。
也請告訴我：這個專案有沒有用到 Gemini API（需要 API 金鑰）？
然後安裝需要的套件，啟動開發伺服器，告訴我網址。
```

打開 AI 給的網址（通常是 `http://localhost:3000`），確認作品和在 AI Studio 裡看到的一樣。

> [!NOTE]
> Windows 若跳出「防火牆」視窗，請按「**允許**」。其他錯誤，把錯誤訊息整段貼給 AI 請它處理（見 [遇到問題怎麼辦](../01-install/README.md#遇到問題怎麼辦)）。

### 作品有用到 Gemini API 的話

會辨識圖片、自動出題、和你對話的 App，通常都用到 Gemini API。在 AI Studio 裡，金鑰是自動提供的；搬到這台電腦後，要用**你自己的金鑰**，AI 功能才能運作。沒有用到的作品，跳過這一段。

1. **申請金鑰**：用瀏覽器打開 [Google AI Studio](https://aistudio.google.com)，用你的 Google 帳號登入，進入 **Get API key**（API 金鑰）頁面，建立一把金鑰並複製下來。學校帳號無法建立的話，改用個人 Gmail。
2. **請 AI 建立設定檔**（先不要把金鑰貼給 AI）：

   **Prompt 5：建立金鑰設定檔**

   ```text
   請建立 .env.local（有 .env.example 的話照它的格式；沒有的話告訴我變數名稱），金鑰的位置先留空，告訴我要貼在哪一行。
   再確認 .env.local 有被 .gitignore 排除，不會被推上 GitHub。
   ```

3. **自己貼上金鑰**：在左邊檔案總管點開 `.env.local`，把金鑰貼在 AI 說的位置，按 `Ctrl + S` 存檔。
4. 請 AI 重新啟動開發伺服器，試試 AI 功能能不能用。

> [!IMPORTANT]
> **金鑰就像密碼**：不貼進 AI 對話框、不推上 GitHub、不傳給別人。萬一外流了，回到 AI Studio 的金鑰頁面把它刪除，再建立一把新的。
>
> 電腦還原後 `.env.local` 也會消失，**每次上課都要重做第 2～4 步**；金鑰可以回到同一個頁面複製。

## Step 3：請 AI 修改一項功能

先想好**一件**你想改的事：可能是一個不順手的地方、一個小 bug，或一個想加的小功能。例如「分數改成顯示最高分」、「按鈕改成大一點、顏色明顯一點」、「加一個重新開始的按鈕」。

**Prompt 6：先問做法**

```text
我想〔你想改的事〕。請先不要改程式，告訴我你打算改哪些檔案、怎麼改。
```

看得懂、也同意的話，再說：

**Prompt 7：動手修改**

```text
照這個做法修改。改好後告訴我怎麼確認。
```

AI 改過的地方，會用紅、綠底色標出新舊差異，旁邊有 **Accept**（接受）和 **Reject**（退回）。看過再接受。

回到瀏覽器試試看：照你想的運作嗎？原本的功能還正常嗎？不對的地方，直接告訴 AI 哪裡不對。

## Step 4：下課前保存作品

電腦關機後會還原，所以要把作品存到 GitHub。git 和 GitHub 的觀念第四堂會細講，今天先照做。

先截一張作品畫面：按 `Win + Shift + S` 框選畫面，點螢幕右下角跳出的通知，在剪取工具按「儲存」，存進作品資料夾裡的 `screenshots` 資料夾（沒有就新建一個）。第六堂做成果簡報時會用到。

接著把作品（連同截圖）存到 GitHub：

**Prompt 8：存到 GitHub**

```text
請把這個資料夾用 git 存成一個版本（說明寫「第三堂：〔你改了什麼〕」），推上 GitHub。
這個資料夾還沒有連到 GitHub 的話，用 gh 建立 private repo，名稱 my-app。
```

到 GitHub 網頁打開你的 repo，看得到檔案和截圖就完成了。**記下你的 repo 名稱**（A 方案是你原本的 repo 名稱，B 方案是 `my-app`），之後每堂都要用。接著：

1. 到 e-Peer 寫今天的紀錄（見下方），貼上 repo 網址。
2. 照 [下課前步驟](../01-install/README.md#每週上課與下課要做的事) 登出 GitHub 並重新開機。

## 📝 e-Peer 紀錄

在 e-Peer 作業的文字欄簡單記錄：

1. **今天做了什麼？** 例如：把作品搬到 Antigravity，請 AI 把〔…〕改成〔…〕。
2. **遇到什麼問題？怎麼嘗試解決？** 例如：一開始跑不起來，把錯誤訊息貼給 AI 後，它幫我〔…〕。
3. **作品或 GitHub 連結**：貼上你的 repo 網址；有截圖就上傳。

這些紀錄第六堂會用來做成果簡報，寫得越具體，之後越輕鬆。

## 本單元學到的事

- **git clone** 能把 GitHub 上的作品下載到電腦；只有 ZIP 檔也能接手。
- 改程式前**先問 AI 做法**，看懂、同意了再動手。
- **API 金鑰就像密碼**：放在 `.env.local`，不貼進對話框、不推上 GitHub。

## 附錄：從零做一個小遊戲

如果你還沒有 AI Studio 作品，在「文件」裡新建一個空資料夾 `my-app`，用 **Open Folder** 打開，貼上：

```text
在這個資料夾建立 Vite + React 專案，做一個「記憶翻牌」遊戲：
16 張牌、翻到相同的兩張就消除，顯示步數和計時，
全部消除後顯示「完成」和重新開始按鈕，介面用中文。
完成後幫我啟動開發伺服器，告訴我網址。
```

也可以把「記憶翻牌」換成你想做的題目。做好之後，從 Step 3 接著做。
