# 成果發表：展示你的作品

展示你的作品，分享修改過程、遇到的問題與學習心得。

**期末成果：一個可以操作的作品，加上一份簡短的成果簡報。** 作品不用很大，重點是有自己的想法，並能說明自己如何和 AI 一起完成。

> **課前準備**：完成 [成果簡報](../05-skill-report/README.md) `report.pptx`。

---

## 上台前準備（上課一開始，約 20 分鐘）

電腦已經還原，先把作品和簡報找回來：

1. 照 [登入 GitHub](../01-install/README.md#登入-github每次上課都要做) 的步驟登入。
2. **簡報**：在「文件」裡新建資料夾 `my-report`，用 **Open Folder** 打開，請 AI 把你 GitHub 上的 `my-report` clone 回來，打開 `report.pptx` 確認。
3. **作品**：
   - 有發布網址的：用瀏覽器打開，確認能正常操作。
   - 沒有網址的（例如有用 Gemini API 的作品）：另開資料夾 `my-app`，照「功能改進與 GitHub」的 [Step 1](../03-github/README.md#step-1把作品找回來) clone 回來、啟動，需要的話重新放入金鑰。
4. 把簡報和作品的視窗都開好，輪到你時可以直接切換。

## 發表流程

每個人約 **5～6 分鐘**：

| 流程 | 時間 | 內容 |
| :--- | :--- | :--- |
| 展示作品 | 約 2 分鐘 | 實際操作給大家看：主要功能、你最滿意的地方 |
| 簡報 | 約 2 分鐘 | 修改過程、遇到的問題、AI 犯錯時你怎麼發現 |
| 問答 | 約 1～2 分鐘 | 回答同學和老師的問題 |

> [!TIP]
> 講者備註就是你的講稿。用 PowerPoint 的話，可以開「簡報者檢視畫面」看著講；用 LibreOffice Impress 的話，可以另外開一個視窗打開 `talk.md` 對照。

### 可能被問到的問題

- 你的作品裡，哪個部分是你自己決定的，哪個部分是 AI 決定的？
- 你怎麼確定 AI 這次沒有出錯？
- 如果重來一次，你會怎麼跟 AI 說？
- 你參考了哪個開源作品？改了什麼？

### 評分參考

| 項目 | 比重 | 看什麼 |
| :--- | :---: | :--- |
| 作品 | 30% | 可以操作，有自己的想法和改進 |
| 過程與查證 | 30% | 說得出修改過程、遇到的問題，以及 AI 錯在哪、你怎麼發現 |
| 簡報 | 20% | 內容符合自己的實作紀錄，清楚易懂 |
| 問答 | 20% | 能說明自己的作品和做法 |

## 選做：把簡報做成有配音的影片

無法現場報告，或想多做一點的同學，可以把簡報的**講者備註變成旁白**，做成一支有配音和字幕的影片。

在 `my-report` 資料夾裡，對 AI 說：

**Prompt：做成影片**

```text
把 report.pptx 做成影片 report.mp4：
1. 用 LibreOffice 把簡報轉成 PDF，再把每一頁轉成 1920×1080 的圖片
2. 每一頁的講者備註當旁白，用 uvx edge-tts 的台灣中文聲音（zh-TW-HsiaoChenNeural）產生配音
3. 每頁畫面停留到旁白講完再多 0.5 秒，用 ffmpeg 合成 mp4
4. 同時產生字幕檔 report.srt
完成後告訴我影片總長度。
```

整個流程是這樣：

```text
report.pptx ──LibreOffice──▶ 每頁一張圖片
講者備註   ──edge-tts────▶ 每頁一段配音
圖片＋配音 ──ffmpeg──────▶ report.mp4（＋ report.srt 字幕）
```

看一遍影片，檢查：

- [ ] 每頁的畫面和旁白對得上嗎？
- [ ] 名字、英文、數字唸得對嗎？唸錯的，把旁白改成「照發音寫」，再請 AI 重新產生。
- [ ] 有沒有你不認同、或不是你做的內容？

> [!NOTE]
> edge-tts 使用微軟的線上語音服務，偶爾會暫時失效（出現 403 等錯誤）。遇到時請 AI「改用 Windows 內建的中文語音」，聲音比較機械，但不需要網路。

做好後，記得推上 GitHub：「把 report.mp4 和 report.srt commit 並推上 GitHub」。

## 📝 e-Peer 紀錄（最後一次）

1. **今天做了什麼？** 發表了什麼作品。
2. **遇到什麼問題？怎麼嘗試解決？** 例如：發表前作品跑不起來、問答時被問倒的問題。
3. **作品或 GitHub 連結**：作品網址、`my-report` 的 repo 網址。
4. **回顧這學期**：和 AI 一起做作品，你覺得最有收穫的是什麼？AI 最常在哪裡出錯？

最後照 [下課前步驟](../01-install/README.md#每週上課與下課要做的事) 登出 GitHub 並重新開機。
