## 課前準備

| 項目 | 說明 |
| :--- | :--- |
| **上課電腦** | 電腦教室的 Windows 電腦。每次開機都會還原，Antigravity 和課程工具由老師在上課前裝好 |
| **Google 帳號** | 登入 Antigravity 和 AI Studio。學校帳號可能被限制，建議用個人 Gmail |
| **GitHub 帳號** | 幾乎每次上課都會用到，也是保存作品的地方。請先到 <https://github.com> 註冊，並**完成信箱驗證** |
| **你的 AI Studio 作品** | 你在 AI Studio 做的 App。有存到 GitHub 的記下網址；沒有的，「接手自己的專案」會教你下載成 ZIP 檔 |

> [!WARNING]
> 電腦會還原，**每次下課前都要把作品推上 GitHub**，並登出帳號、重新開機。做法見 [每週上課與下課要做的事](01-install/README.md#每週上課與下課要做的事)。

## 每次上課都一樣的做法

1. 在「文件」（Documents）裡**新建一個資料夾**，用 **Open Folder** 打開。AI 只會在打開的資料夾裡工作。
2. 把講義裡的 **Prompt 貼給 AI**。AI 要執行指令時會先詢問，確認後按 **Accept / Run**。
3. **檢查 AI 的產出**：照講義的檢查清單逐項確認，發現錯誤就告訴 AI 哪裡不對。
4. **下課前**：推上 GitHub，在 e-Peer 寫紀錄。

遇到問題時，把錯誤訊息整段貼給 AI 請它處理；常見狀況見 [遇到問題怎麼辦](01-install/README.md#遇到問題怎麼辦)。

## 📝 e-Peer 紀錄

每次上課最後，在 e-Peer 作業的文字欄簡單記錄：

1. **今天做了什麼？**
2. **遇到什麼問題？怎麼嘗試解決？**
3. **有作品或 GitHub 連結就貼上，有圖片再上傳。**

不用另外填寫學習單。這些紀錄之後會用來做成果簡報，寫得越具體，之後越輕鬆。
