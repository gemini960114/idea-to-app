# 延伸 B：AI 讀課本做筆記，做出一本查得回去的筆記

約 45 分鐘。讓 AI 讀高中生物課本第 1 章，做出 1-1「細胞學說的發展歷程」的筆記；再自己查證、換一個模型比較，最後請 AI 找延伸閱讀。

**重點：好筆記要「查得回去」。** 每一點都附上課本頁碼，才能確認 AI 寫的是課本的內容，而不是它自己補的。

> 電腦會還原。想保存筆記的話，開始前先照 [登入 GitHub](../01-install/README.md#登入-github每次上課都要做) 的步驟登入。

> **課前準備**：老師會提供課本的 Markdown 檔（由課本 PDF 轉換，**僅限課堂使用，請勿上傳或分享**）：
>
> - `第1章_細胞的構造與功能.md`
> - `images/` 資料夾（課本插圖；要和 md 檔放在同一層，md 裡的圖片才顯示得出來）
>
> 每一頁開頭都標有 `<!-- 課本第 N 頁 -->`，AI 可以依此引用頁碼。

---

## Step 1：準備資料夾

1. 在「文件」（Documents）裡新建一個資料夾 `biology-notes`。
2. 把老師提供的 `第1章_細胞的構造與功能.md` 和整個 `images/` 資料夾放進去（兩者放在同一層）。
3. 用 **Open Folder** 打開 `biology-notes`，在左邊點開 md 檔看看：每頁開頭的 `課本第 N 頁` 就是課本上印的頁碼。

## 練習 1：請 AI 列目錄（5 分鐘）

先確認 AI 真的讀到了正確的檔案。

**Prompt 1：列目錄**

```text
請閱讀 第1章_細胞的構造與功能.md，列出這一章的節和小節，以及每一節從課本第幾頁開始。
```

拿出課本（或翻 md 檔）對照：1-1 從第 8 頁開始嗎？其他節的頁碼對嗎？

## 練習 2：做 1-1 的筆記（10 分鐘）

**Prompt 2：做筆記**

```text
請根據 第1章_細胞的構造與功能.md 的 1-1「細胞學說的發展歷程」，做一份筆記存成 notes/1-1.md：
1. 重點整理（5～8 點）
2. 名詞小辭典（重要名詞與解釋）
3. 科學家時間軸，用表格：年份｜科學家｜貢獻
每一點後面都要附上課本頁碼，例如（p.9）。課本沒有寫的內容不要加，年份不確定就寫「課本未提及」。
```

打開 `notes/1-1.md`，先讀一遍：看得懂嗎？有沒有漏掉你覺得重要的內容？

## 練習 3：當偵探，查證筆記（10 分鐘）

照筆記上的頁碼，回到課本（或 md 檔，用 `Ctrl + F` 搜尋）找證據，完成三個任務：

| 任務 | 要做什麼 |
| :--- | :--- |
| **任務 1：年份對嗎？** | 時間軸上的每個年份，都到筆記寫的那一頁找找看，課本真的這樣寫嗎？ |
| **任務 2：許旺是哪一年？** | 許旺提出「所有生物皆由細胞所構成」。筆記有沒有寫出年份？到課本找找看，課本有寫這個年份嗎？ |
| **任務 3：虎克看到了什麼？** | 虎克在軟木栓切片裡看到的，是完整的細胞嗎？筆記怎麼寫？課本怎麼寫？ |

> [!NOTE]
> 任務 2 是陷阱題。就算 AI 補上的年份是「對的知識」，只要**不是出自課本**，筆記上就不該寫成課本的內容；寫報告時，這就是「沒有出處」。

發現錯誤時，直接告訴 AI 哪裡不對，請它修正。例如：

```text
時間軸上的〔哪一項〕寫錯了，課本第〔N〕頁寫的是〔…〕，請改正；課本沒寫的請改成「課本未提及」。
```

## 練習 4：換一個模型比較（5 分鐘）

不同的 AI 會犯不同的錯。開一個**新對話**，在下方換成**另一個模型**，貼上一樣的 Prompt 2，但把檔名改成 `notes/1-1_另一個模型.md`。

比較兩份筆記：

- 哪一份的重點比較完整？
- 兩份筆記有沒有說法不一樣的地方？誰對？（翻課本確認）
- 有沒有哪一份加了課本沒有的內容？

## 練習 5：找延伸閱讀（10 分鐘）

第 1 章的章首（課本第 4 頁）介紹了「**再生醫療**」和幹細胞。請 AI 幫忙找延伸閱讀：

**Prompt 3：找延伸閱讀**

```text
請找 2～3 篇適合高中生閱讀、介紹幹細胞或再生醫療的中文科普文章，
列出標題、作者或來源網站、網址，以及一句話說明內容，存成 notes/延伸閱讀.md。
```

接著**每個網址都要點開確認**，在檔案裡每一篇後面標註：

| 標註 | 意思 |
| :--- | :--- |
| ✅ 找得到 | 網址打得開，標題和內容都對得上 |
| ⚠️ 內容不符 | 網址打得開，但標題或內容和 AI 說的不一樣 |
| ❌ 找不到 | 網址打不開，或根本沒有這篇文章 |

> [!WARNING]
> **AI 很常編造不存在的文章、論文和網址**，而且標題、作者都寫得很像真的。引用任何資料之前，一定要自己點開確認。

## 練習 6（選做）：自我測驗

```text
根據 notes/1-1.md 和課本，出 5 題選擇題，每題附上答案和課本頁碼，存成 notes/1-1-測驗.md。
```

先遮住答案自己做一遍，再對答案。答案有疑問時，翻到題目附的頁碼確認，題目和答案也可能出錯。

## 你的筆記本

做完後，`biology-notes/notes/` 裡會有：

| 檔案 | 內容 |
| :--- | :--- |
| `1-1.md` | 查證過的 1-1 筆記 |
| `1-1_另一個模型.md` | 另一個模型做的筆記 |
| `延伸閱讀.md` | 確認過的延伸閱讀清單 |
| `1-1-測驗.md` | 自我測驗（選做） |

電腦會還原，筆記要**推上 GitHub 才會留下來**（見下一節）。有時間的話，用同樣的方法做 1-2「細胞的構造與功能」的筆記。想做成簡報的話，可以用第六堂的 [pptx Skill](../05-skill-report/README.md)；用了課本插圖的簡報只能在課堂上使用。

## 下課前：保存筆記

想保留筆記的話，下課前推上 GitHub。**課本的 Markdown 和圖片有版權，不能推上去**：

**Prompt 4：保存筆記**

```text
把這個資料夾推上 GitHub，建立 private repo，名稱 biology-notes。
課本檔案 第1章_細胞的構造與功能.md 和 images/ 資料夾有版權，請用 .gitignore 排除，不要推上去。
推完後列出 repo 裡有哪些檔案，讓我確認。
```

到 GitHub 網頁打開 `biology-notes`，確認**只看得到 `notes/` 和 `.gitignore`**，沒有課本的 md 檔和圖片。接著照 [下課前步驟](../01-install/README.md#每週上課與下課要做的事) 登出 GitHub 並重新開機。

---

## 本單元學到的事

- 請 AI 做筆記時，**要求附上頁碼**，筆記才查得回去。
- AI 會用自己的知識補上資料裡沒有的內容，就算內容是對的，也不是這份資料的出處。
- 不同模型會犯不同的錯，**比較兩份結果**能幫你找出問題。
- **AI 找的文章、網址一定要點開確認**，它可能編出根本不存在的資料。
