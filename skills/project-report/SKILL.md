# 實作成果簡報（project-report）

幫高中生把「自己和 AI 一起做作品」的過程，整理成一份**每一點都查得到出處**的成果簡報。學生要能對每一句話負責，所以**沒有來源的內容一律不寫**。

## 素材（都在目前開啟的資料夾）

| 素材 | 位置 | 說明 |
| :--- | :--- | :--- |
| e-Peer 紀錄 | `records/e-peer.md` | 學生從 e-Peer 複製貼上的各堂紀錄（做了什麼、遇到的問題、連結） |
| 作品 repo | 學生告訴你的 GitHub repo 名稱 | 用 `gh repo clone <帳號>/<repo> sources/<repo>` 下載到 `sources/`，用 `git log` 讀 commit 紀錄 |
| 截圖 | `images/` | 作品畫面；也可以從作品 repo 裡找 `.png` 檔複製過來 |

`sources/` 只是暫存，要加進 `.gitignore`，不要推上 GitHub。`gh repo clone` 失敗（名稱錯誤、沒有登入）時，請學生確認 repo 名稱或先登入，**不要猜 repo 名稱**。

## 流程（照順序做，每一步完成後告訴學生結果）

### 1. 盤點素材

列出找到的素材：e-Peer 有哪幾堂、每個 repo 有幾個 commit、有哪些截圖。缺少的素材**直接問學生**，不要自己補。

### 2. 整理時間軸 → `records/timeline.md`

用表格整理：

| 堂次／日期 | 做了什麼 | 遇到的問題 | 怎麼解決 | 來源 |
| :--- | :--- | :--- | :--- | :--- |

- 「來源」寫 `e-Peer 第N堂`、`commit 前7碼（repo 名稱）`，或 `學生口述（日期）`（學生在對話中補充的內容），可以同時列多個。
- 只寫素材裡有的事。commit 說明太簡略（例如只寫「update」）時，可以看該 commit 改了哪些檔案再描述，並在來源註明「依 commit 內容推斷」。
- 把「AI 犯錯、學生發現並修正」的事件**特別標出來**（加上 ⚠️），這是報告最重要的部分。

完成時間軸後**停下來**，請學生確認每一列是否符合事實、有沒有漏掉的事件；學生確認後才寫講稿。

### 3. 寫講稿 → `talk.md`

固定 6 頁，對象是同班同學：

1. **題目與我**：作品名稱、做這個作品的原因
2. **我的作品**：主要功能、截圖、網址（沒有發布就寫「本機展示」）
3. **改進過程**：從 AI Studio 到現在，最重要的 3～4 次修改
4. **遇到的問題與解決**：1～2 個具體的例子
5. **AI 犯錯，我怎麼發現**：時間軸裡標 ⚠️ 的事件；沒有的話，問學生
6. **我學到的事與下一步**

每一頁包含：

- 標題、2～4 個重點，**每個重點後面標 `〔來源：…〕`**（對應時間軸的來源欄）
- 一段講者備註：第一人稱「我」、口語、約 30～40 秒；備註裡的事實也要在時間軸找得到
- 建議的截圖檔名（`images/` 裡的檔案），沒有適合的就寫「不放圖」

找不到來源的內容，寫成 `〔待補：需要學生說明…〕`，不要編造。

### 4. 停下來，請學生確認

把 6 頁的重點和來源列給學生看，**明確請學生逐頁確認**：哪些不是他做的、哪些說法要改、哪些〔待補〕要補。學生確認或修改 `talk.md` 之前，**不要進行下一步**。

### 5. 做成 PPTX → `report.pptx`

使用 pptx skill（若專案裡有 `.agents/skills/pptx/`，照它的做法）：

- 投影片上**不顯示** `〔來源：…〕` 標記；來源保留在 `talk.md` 和 `records/timeline.md`
- 文字都是可以編輯的文字框，不要把整頁做成圖片
- 講者備註放 `talk.md` 的備註
- 截圖照 `talk.md` 指定的檔案放，不變形、不裁掉重要部分
- 做完把每一頁轉成圖片檢查（LibreOffice 轉 PDF，再用 Python 的 PyMuPDF 轉圖片；Windows 沒有 pdftoppm），修正文字超出或重疊

### 6. 最後核對

用表格列出每一頁的重點與對應來源，標出任何對不上的地方，交給學生做最後確認。

## 規則

- **不編造**：功能、問題、修改、心得，都只能來自素材或學生親口說的話。
- **不洩漏祕密**：不讀取、不引用 `.env`、`.env.local` 或任何 API 金鑰。放進簡報的截圖，先確認畫面裡沒有金鑰、密碼或個人資料；有的話提醒學生重新截圖。
- **尊重來源**：作品參考或改作了開源專案的話，在第 2 或第 3 頁註明來源。
- 用繁體中文、台灣用語，句子簡短，適合高中生上台講。
